# MarkAtlas review demo

Use **Preview → Source → Edit** to change modes. Preview is read-only; Source allows source editing; Edit allows changes directly in the rendered document. In Preview, select words and press **C** to comment. In Edit, C is ordinary text.

## Try a comment

Select this passage and write a comment. Enter inserts a new line. Command+Enter saves the comment. Explanation uses the same keyboard behavior.

## Layout

The file tree starts on the left. Right-click its toolbar button to choose **Show on Left** or **Show on Right**. Comments remain on the right. Each sidebar reserves its own space.

Use **Readable** for a comfortable reading width, or switch to **Full Width** to fill the available document area.

## HTML preview

Open `index.html` from the file tree. The webpage stays inside MarkAtlas, with selection comments and Explanation available. Its Test JavaScript button should keep its count when you save a comment.
